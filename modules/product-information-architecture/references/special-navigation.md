# 一覧・探索・言語切替

各指示はDRAFT。ID先に原典・依存・失敗例・適用限界がある。

| 場面・ルール | 指示と例外 | 確かめ方 |
|---|---|---|
| [201](../../../registry/A/skills/A-IU-201.json) よく使う項目を頻度で並べ替える一覧 | 固定する項目を決め、自動のおすすめは別枠に置く。並べ替えを利用者が選んだ場合は元の順序へ戻せるようにする。 初めて来た人には過去の順序を想定しない。個人履歴を共有端末に出さない。 | 初回と再訪で同じ項目を探し、誤選択と所要時間を別々に記録する。 |
| [202](../../../registry/A/skills/A-IU-202.json) 階層の深いページに直接到着する場合 | パンくずには親子階層、進捗表示には作業の段階を入れる。複数の親がある対象では表示する経路の意味を明記する。 階層が1段しかない一覧に人工的な親を増やさない。 | 深いページに直接入り、親分類への移動と作業の前段階への移動を別々に実行する。 |
| [203](../../../registry/A/skills/A-IU-203.json) 分類の階層を浅くすると1画面の選択肢が急増するとき | 幅と深さが異なる試作に同じ対象を配置し、第一選択の正否、引き返し回数、最終到達を比較する。 正解経路が複数なら経路の短さだけで失敗と採点しない。 | 馴染みのある対象と初めて見る対象を用意し、両方で分類間の移動を記録する。 項目探索とポインター移動の時間は分けて扱う。 |
| [204](../../../registry/A/skills/A-IU-204.json) 部署名や制度名から探せないサービス | 代表的な用件の語で検索し、検索欄・入力候補・結果見出しのどこで用件との対応が失われるかを確認する。 同じ語が地域ごとに別制度を指すときは統合せず範囲を添える。 | 通称と正式名の両方を試し、目的地を開く前に識別できたかを記録する。 |
| [205](../../../registry/A/skills/A-IU-205.json) 全体翻訳と一部ページの翻訳が混在するとき | 利用者が読める言語名で選択肢を示し、切替先が同じページか別の案内ページかを表示する。 対訳が存在しないページには内容の異なる翻訳済みページを同じ内容として結び付けない。 | 深いページから各言語に切り替え、対象、回答、次の行動がどう引き継がれたか照合する。 |
