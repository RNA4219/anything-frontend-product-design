# 階層・開閉・入力

入口の共通手順を踏み、該当する項目を使う。リンク先に入力、成果、失敗例、検証状態と原典がある。

## 階層データを矢印キーで操作するとき [C-UI-209](../../../registry/C/skills/C-UI-209.json)

展開状態と選択状態を別に伝える。開く・閉じる・親へ移るキーと、項目を選択する操作を定める。 子に選択を残した状態で親を閉じて再展開し、現在位置・選択内容・読み上げを照合する。 見出し・リンクをたどる探索でも同じ対象へ到達できるか確認する。

例外・適用条件: 通常のサイトナビゲーションで単純なリンク一覧が足りるときは複合ツリーを導入しない。

## 複数セクションを独立に開閉する画面 [C-UI-210](../../../registry/C/skills/C-UI-210.json)

見出し内の操作でどの本文が開くかを対応付け、開閉状態を通知する。閉じた領域にフォーカスを残さない。 同じ見出し語を含む2区画を順番に開閉し、対象の本文だけが変わり、非表示部品に移動しないか試す。

例外・適用条件: 手順上必須の判断や全項目の比較を繰り返す内容は常時表示も試す。

## アップロードがファイル形式・件数・容量に制限されるとき [C-UI-211](../../../registry/C/skills/C-UI-211.json)

選択前に制限を示し、選択済みの名前とファイルごとの結果、置換・削除を表示する。選択とサーバー到達を区別する。 同名2ファイル、容量超過、送信途中の切断を試し、どれが利用可能かと再選択の対象を照合する。

例外・適用条件: 機密ファイルの保存・プレビューはサービスの保持条件に合わせる。

## 意見欄や申請理由に長さの上限がある場合 [C-UI-212](../../../registry/C/skills/C-UI-212.json)

上限と数え方を示し、超過内容を黙って切り捨てず修正できる状態で残す。文字入力中の通知頻度を決める。 貼り付け、日本語変換確定、絵文字を含む入力で、表示残数・エラー・保存条件を比較する。

例外・適用条件: 空白・改行・結合文字の処理は実際のサーバーの規則に合わせる。

## タッチや画面読み上げでアイコン操作を探す場合 [C-UI-213](../../../registry/C/skills/C-UI-213.json)

触れた対象の役割・名前を取得してから起動できるようにする。見えるラベルとアクセス可能な名前を対応させる。 画面を見ずに候補を順に探索し、対象を聞いてから起動できるか、探索中に副作用が発生しないかを確認する。

例外・適用条件: 研究用ジェスチャーを各OSの標準ジェスチャーに優先させない。
