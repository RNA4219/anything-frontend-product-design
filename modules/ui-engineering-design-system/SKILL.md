# UI実装・デザインシステム

利用者が終える作業と、完了を確かめられる事実を一文で書く。利用課題ID、開始時のデータ、対象環境、状態と受入条件があれば受け取る。既存画面があれば、対象の操作を同じ入力で最後まで試し、詰まった場所を特定する。状態が未定義なら、判断を変える条件と仮定を書き、[担当間の受け渡し](../../references/handoff.md) に沿って仕様・実装と照合する。

## 部品を選ぶ

1. 部品カタログ、既存利用箇所、ブラウザーの要素を確認する。名前・役割、操作、値、状態、フォーカス、通知が合う部品を再利用する。表示だけの差は既存のバリアントや意味トークンで表せるか確認する。
2. 個々の契約が合い、仕事の組み立てが画面固有なら、既存部品を合成する。拡張する場合は、追加する入力・出力・既定値と既存利用箇所の互換性を示す。合成で利用者の操作が途切れる、状態表現が欠ける、あるいは元の役割を変えるなら、その失敗を再現してから局所実装を検討する。
3. 検証済みの複数用途に共通し、既存の部品や合成で解けない場合は、共有部品化の根拠を残す。対応環境、既存利用箇所への影響、維持する担当、適用できない用途を明記する。新規と現行の両方が候補なら、同じ課題・データ・入力方法・成功条件で比べる。 [採用の根拠 GOV-1・GOV-2](../../research/ui-engineering-design-system/sources.md)

## 操作と状態を契約にする

- アクションは `button`、ページ移動はリンク、排他的な短い候補はラベル付きの同名 `radio` を候補にする。関連する入力は `fieldset` と `legend` でまとめる。単一候補しか存在しない場合は、候補の情報を示して続ける操作を検討する。既存の独自部品を採用するときは、名前・役割・値、キー操作、画面内の順序、フォーカスを実機で確認する。 [HTML-1・HTML-2・APG-1](../../research/ui-engineering-design-system/sources.md)
- 部品ID、表示する値とその取得元、状態・操作・遷移条件、データの保持・更新、到達先のフォーカス、画面表示・通知、対応する受入条件を書く。値・無効状態・送信可否は同じ状態から決める。読み込み、空、保留、競合、結果不明、成功のうち該当するものを扱う。
- 操作して領域が切り替わり起点が消える場合は、新しい見出しなど作業を続けられる位置へ移す。戻る先に使える起点があれば復帰する。同じ領域で進捗や結果だけが変わる場合は、先に置いたライブ領域を更新し、フォーカスを保つ。動いている見出しと通知で同じ文言を重ねないよう確認する。エラーには対象・分かった事実・復旧操作を可視テキストで添える。 [ARIA-1・WCAG-1・WAI-1・WAI-2](../../research/ui-engineering-design-system/sources.md)
- 送信中に同じ操作を受け付けない。競合で変更が成立しなかった場合は確定値を保持し、最新の有効な候補へ戻す。結果不明の場合は、現在値と必要なら操作ID・版を照合し、適用済みなら確認表示へ、未適用と判明した場合は再確認へ進む。現在値だけで確定を判断できない場合は、不明状態と復旧導線を保つ。再送の同一性、キーの有効期間、同一キーを使える入力、同時更新の扱いをサービスの契約で確認する。 [STR-1・STR-2・AWS-1](../../research/ui-engineering-design-system/sources.md)

## トークンの変更と受け入れ

視覚方針や既存テーマの値を、面・文字・操作・フォーカスなどの用途に対応付ける。値を変える前に、別名の参照元と利用箇所、対で変わる面と文字、利用可能・選択・無効・エラーなどへの波及を調べる。複数部品が同じ意味で値を使うときは共通の意味名を使い、一つの部品に固有の判断は部品側で管理する。実画面で色以外の状態の手がかり、フォーカス、狭幅での情報と操作の関係を再確認する。色・書体・構図の選定が必要なら Art Direction に、優先情報、主要操作、最小表示条件を渡す。 [USW-1・DTCG-1・AD-1](../../research/ui-engineering-design-system/sources.md)

試作や実装では、同じ課題をキーボードと該当するポインター操作で完了する。長いラベルや狭幅で意味・フォーカス表示・操作が欠けないかを確かめる。保留中の連打、戻る、競合からの復旧、結果不明からの照合、完了後の再表示など、対象の状態を一つずつ実行する。報告には入力、環境、実際に観察した結果、未確認の組合せを含める。
