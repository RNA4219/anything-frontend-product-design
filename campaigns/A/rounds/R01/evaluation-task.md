# 公共施設の予約サービスを整理する

brief.jsonの機能を維持・統合・延期・削除に整理し、役割ごとの入口、画面の目的、判断に使う情報を設計してください。見た目のデザイン変更は不要です。入力の予約2件を見分けて、変更対象を選べることを示してください。利用者・職員の機能一覧に重複があり、減らせるものは整理したいです。

納品物: plan.json（共有する契約に準拠）、design.md（判断理由と未確認条件）、preview.html（予約の識別に必要な情報とナビゲーションの静的な見取り図。業務操作を実装したと主張しない）。提示された入力とSkill以外の資料は読まないでください。モデルの一般知識は使用できます。追加エージェント、ネットワーク、git操作は不要です。
