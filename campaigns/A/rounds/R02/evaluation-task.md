# Training catalogue design task

入力の同名研修C-101/C-202を、対象ID・受講条件・開催条件で区別できる画面構成を設計する。全研修の探索、登録済み研修、旧ブックマーク、検索0件の解釈を一つの案へまとめる。学習機能/申込処理/APIを新規実装する必要はない。

`plan.json`（共有入出力契約1.1）、`design.md`（判断・代替・限界）、`preview.html`（標準HTMLの情報見取り図）を作る。必要な追加分析はdecision_notesに書ける。入力条件以外の利用者評価・実装検証・意匠を捏造しない。

ブラウザー描画は環境によって未実施になり得る。HTMLに実動作を装った処理完了を表示せず、静的例は静的例とする。
