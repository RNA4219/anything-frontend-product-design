# 調査の再現

[設計ルールと出典の一覧](design-evidence/README.md)では、適用場面から公式ガイドの参照箇所と学術論文を引ける。

担当別のディレクトリに、論点と出典を対応づけた `map.md`、調べた経路と終了理由を示す `log.md`、取得と検索の記録、知識分解の結果を置く。調査中は、まず原典と位置を記録する。一次資料には文書名、著者・組織、版または取得日、該当箇所、URLを添える。

公開リポジトリへの原文同梱は再配布条件を確認できるものを対象とし、条件に従って出典と権利表示を添える。ローカルに保存して確認した原文の記録には、公開元のURL、版、該当箇所を残す。

設計原則には、原典が示す条件、今回採用した判断、適用範囲を追えるよう出典IDを付ける。Art Directionの既存の指示を再利用する場合は、参照した版と該当箇所を残す。
