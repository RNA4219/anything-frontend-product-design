<a id="returns-apple-returns-desktop"></a>

## Apple（PC幅）

米国の標準返品は受取日から14暦日。Appleから直接購入した商品が対象で、付属のコードや書類も同梱する案内がある。別途ホリデー返品条件も表示された。

標準返品の見出しと箇条書きに期間と対象が並び、ホリデー条件と区別されている。

画面で照合した表示　Standard Return Policy の14暦日

記録した操作　クリック「Learn more about refunds and returns」 → スクロール「該当する本文へ移動」

[公式の入口](https://www.apple.com/shop/help) · [到達URL](https://www.apple.com/shop/help/returns_refund)

## IKEA（PC幅）

米国では新品未開封品は365日以内、開封品は180日以内に購入証明とともに返品できる。植物、裁断済み布、特注天板、現状販売品は返品対象外と表示。

返品ポリシーの本文に期間と購入証明が並び、対象外の商品は太字で示される。

画面で照合した表示　365日・180日と購入証明

記録した操作　クリック「Learn more」 → クリック「Accept（Cookie同意）」 → スクロール「該当する本文へ移動」

[公式の入口](https://www.ikea.com/us/en/customer-service/) · [到達URL](https://www.ikea.com/us/en/customer-service/returns-claims/)

## Target（PC幅）

米国ではTargetが販売する大半の商品が90日、レシートのあるTargetブランド商品は365日と表示された。一部商品には別の期間がある。

返品期間が大きな赤い数字で示され、各数字の下に対象条件が添えられている。

画面で照合した表示　90日とTarget販売の大半の商品

記録した操作　クリック「Returns & receipts Start a return or find a receipt」

[公式の入口](https://help.target.com/) · [到達URL](https://www.target.com/returns)

## Argos（スマホ幅）

宅配または店頭受取商品の返品記事に、配送日または受取日から30日と表示された。店頭受取品はArgos店舗に返せる旨も記載。

受取方法のボタンの下に記事見出しと30日の説明が続く。

画面で照合した表示　配送・受取から30日

記録した操作　タップ「How do I return a home delivered item, or product I collected in store?」 → スクロール「該当する本文へ移動」

[公式の入口](https://help.argos.co.uk/) · [到達URL](https://help.argos.co.uk/help/refunds-&-returns/how-do-i-return-a-home-delivered-item-or-product-i-collected-in-store)

<a id="returns-lego-returns-mobile"></a>

## LEGO（スマホ幅）

米国向け案内では荷物を受け取った日から90日以内に無料で返品できる。ギフトカード、Pick a Brick、Minifigure Factory、Create a Minifigureは返品対象外と記載。

Returns見出しの下に90日の本文があり、米国向け手続きと返品対象外が続く。

画面で照合した表示　受取日から90日と対象外商品

記録した操作　タップ「Continue」 → タップ「Reject All」 → タップ「Deliveries, Returns & Cancellations」 → スクロール「返品期間の本文へ移動」

入口は利用するサイトを選ぶダイアログ。

[公式の入口](https://www.lego.com/en-us/service) · [到達URL](https://www.lego.com/en-us/service/help-topics/article/deliveries-returns-and-cancellations)
